[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)](https://www.python.org/)
[![Pytest](https://img.shields.io/badge/pytest-passing-green)](https://docs.pytest.org/)

Мощный инструмент для анализа финансовых транзакций, расчета кэшбэка и управления инвестиционным портфелем. Приложение помогает пользователям отслеживать расходы, оптимизировать кэшбэк и анализировать инвестиционные возможности.

## ✨ Возможности

### 📈 Анализ транзакций
- **Импорт данных** из Excel файлов банковских выписок
- **Категоризация расходов** с автоматическим определением MCC-кодов
- **Анализ кэшбэка** по категориям и периодам
- **Визуализация** основных финансовых показателей

### 💰 Кэшбэк-аналитик
- **Автоматический расчет** кэшбэка по банковским картам
- **Оптимизация категорий** для максимального возврата
- **Персональные рекомендации** по увеличению кэшбэка
- **Месячные отчеты** по кэшбэку

### 📊 Инвестиционный анализ
- **Отслеживание курсов валют** в реальном времени
- **Мониторинг цен акций** (NYSE, NASDAQ)
- **Анализ портфеля** с учетом рыночных тенденций
- **Персональные настройки** предпочтительных активов

### 📱 Удобный интерфейс
- **Веб-интерфейс** на Flask
- **Консольный режим** для быстрого анализа
- **Экспорт отчетов** в JSON и Excel форматах
- **Адаптивный дизайн**

## 🚀 Быстрый старт

### Предварительные требования

- Python 3.8+
- pip (менеджер пакетов Python)

### Установка

1. **Клонируйте репозиторий:**

git clone https://github.com/yourusername/financial-analytics-tool.git
cd financial-analytics-tool ````

### Активируйте виртуальное окружение

**Для Windows:**



````venv\\Scripts\\activate````

**Для Linux/Mac:**

````source venv/bin/activate````

### 3\. Установите зависимости

````pip install -r requirements.txt````

### 4\. Настройте переменные окружения

````cp .env.example .env````

_\# Отредактируйте .env файл, добавив свои API ключи_

## 🔑 Получение API ключей

**Курсы валют:** Получите ключ на [exchangerate-api.com](https://www.exchangerate-api.com/)

**Цены акций:** Получите ключ на [alphavantage.co](https://www.alphavantage.co/)

### Добавьте ключи в файл .env:


````CURRENCY_API_KEY=your_currency_api_key_here````

````STOCK_API_KEY=your_stock_api_key_here````


## 🎯 Использование

### Консольный режим


_\# Запуск с настройками по умолчанию_

````python src/main.py````

## 📝 Подготовка данных

1.  Экспортируйте выписку из банковского приложения в Excel
2.  Убедитесь, что файл содержит следующие столбцы:
    - Дата операции
    - Номер карты
    - Сумма операции
    - Категория
    - Кэшбэк
    - и другие (полный список в utils.py)
3.  Поместите файл в папку data/ или укажите путь при запуске
